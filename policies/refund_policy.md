# Refund and Return Policy

## 1. Return Window
* Customers can return items within **30 days** of the delivery date for a full refund.
* Items returned after 30 days but within 60 days are eligible for store credit only.
* No returns are accepted after 60 days.

## 2. Condition of Items
* Items must be in original, unused condition with all tags attached.
* Electronics must be unopened. If opened, a 15% restocking fee applies.

## 3. Damaged or Defective Items
* If an item arrives damaged or defective, the customer must report it within **7 days** of delivery.
* We will issue a full refund or send a free replacement for damaged items. 
* The customer does not need to pay return shipping for damaged items.

## 4. Return Shipping Costs
* For standard returns (changed mind, wrong size), the customer is responsible for a $5.99 return shipping fee, which will be deducted from their refund.
* For company errors (wrong item sent, damaged), return shipping is free.

## 5. Processing Time
* Refunds are processed within 5-7 business days after we receive the returned item.
